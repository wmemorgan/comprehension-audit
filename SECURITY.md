# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub:

1. Open the [Security tab](https://github.com/wmemorgan/comprehension-audit/security) of this repository.
2. Select **Report a vulnerability**.
3. Describe the issue, the affected version or commit, and the steps to reproduce it.

Do not open a public issue for a security vulnerability.

You will get an acknowledgement within 5 business days. Fixes are released on `main`, and the
advisory is published after a fix is available.

## Supported versions

Only the latest commit on `main` receives security fixes.
